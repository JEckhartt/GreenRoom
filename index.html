Summary prompt
Shared by all chats. Once filled in, the Summarize button appears. {{char}} and {{user}} are filled in.
About the context window. A model only sees a limited amount of text (its context window, in tokens). In a long chat the oldest messages fall out and the character forgets them. Summarize regularly: it writes the not-yet-summarized part into Memory, which is always sent. Summarizing itself also needs the unsummarized part to fit, so don't wait too long. Set a context size a bit below your model's limit (Proxy tab or Settings → Generation), or pick a model with a larger context.

Image prompt

Generation
Show the AI's thinking
Some models ("reasoning" models) think before they answer. On: you can read that thinking, folded above the reply. Off: it's hidden. It is never sent back to the AI.
Show it
Context size
How much of the chat the AI gets to read, in tokens (100 tokens ≈ 75 words). When a chat is longer, the oldest messages are left out. Set it a little below your model's limit, e.g. 30000 for a 32k model. Empty = send everything.
Prompt
Repeat the character card near the latest message
Every reply already ends with a short reminder to stay true to the character card. This also sends the whole personality again right at your latest message, for characters that drift in long chats. Stronger, but it costs the card's tokens with every message. A chat can have its own setting (Chat settings → Prompt).
New chats
Wait before the AI writes the opening
For characters whose opening the AI writes. Off: it starts writing as soon as the chat opens. On: the chat opens with a Start button, so you can change Chat settings first.
A new chat starts with the chat settings of the chat you used last (proxy, preset, prompt, style, image settings…), not its memory, author's note or lorebooks.

Extras
A long-term memory that searches by meaning: with every message, the moments from long ago in the same chat that fit what you write now are given to the AI again. Works with any chat model; the searching is done by an embedding model through OpenRouter.
On for all chats
A chat can be switched on or off by itself in Chat settings → Memory.
Your OpenRouter proxy (its key is used). Proxies that only pass on chat, like LoreBary, can't do this.
Only moments that are no longer in what the AI sees are recalled: older than your context size, or older than the last 60 messages without one. The first time in a long chat, its messages are indexed once (a few cents for a very long chat).

Privacy
Activate dummy account
A second account with its own characters, personas and chats; your settings (proxies, prompts, styles, lorebooks) are copied into it once. Long press the title on the title screen to switch; in the dummy account it says Switch back.
Launch app into dummy account
When the app starts, it opens in the dummy account. Switching back lasts until the app is closed.
Backup
Export saves all characters, personas, chats, images and settings (API keys included) in one file. Keep it in Files or iCloud Drive. Import restores it after reinstalling or on another phone, and replaces everything currently in the app.
Debug
For when the app crashes or something goes wrong: share this file when you report it. It holds errors, crashes, storage use and chat sizes, but no messages, prompts or API keys.
