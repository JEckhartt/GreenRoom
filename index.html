Summary prompt
Shared by all chats. Once filled in, the Summarize button appears. {{char}} and {{user}} are filled in.
About the context window. A model only sees a limited amount of text (its context window, in tokens). In a long chat the oldest messages fall out and the character forgets them. Summarize regularly: it writes the not-yet-summarized part into Memory, which is always sent. Summarizing itself also needs the unsummarized part to fit, so don't wait too long. Set a context size a bit below your model's limit (Proxy tab or Settings → Generation), or pick a model with a larger context.
