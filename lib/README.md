# Libraries bundled with the app

Loaded only when needed, from here (no internet):

- `dummy.js`: the characters and personas of the dummy account (Settings → Privacy).

- `o200k_base.js`: gpt-tokenizer 2.9.0 (MIT), counts tokens in the character editor.
- `pdf.min.js`, `pdf.worker.min.js`: pdf.js 3.11.174 (Apache-2.0), reads PDF files you attach in a chat.

Fonts are in `../fonts` (Google Fonts, SIL Open Font License).
